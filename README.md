Teen Mental Health Prediction

Teen Mental Health Prediction is a Machine Learning-based project developed to identify potential mental
health risks among teenagers by analysing their lifestyle and behavioural patterns. The main objective of 
this project is to predict teenagers' mental health conditions based on factors such as age, sleep hours, 
social media usage, screen time, academic performance, physical activity, stress, anxiety, and depression 
levels. This project is implemented using Python in Google Colab with libraries such as Pandas, NumPy,
Scikit-learn, Matplotlib, and Seaborn. Data cleaning, preprocessing, feature selection, model training, 
and evaluation are performed as part of the implementation. Three machine learning algorithms, namely
Decision Tree, Random Forest, and K-Nearest Neighbors (KNN), are used for prediction. The system classifies 
the results into two categories: At-Risk and No-Risk. The main purpose of this project is to support early 
identification of possible mental health problems and create awareness about teenage mental well-being. In 
the future, this project can be enhanced with real-time sentiment analysis and mobile application development.
